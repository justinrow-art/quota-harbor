# Code of Conduct

We want this project to be useful, careful, and welcoming.

## Expected behavior

- Be respectful, specific, and patient.
- Critique code and decisions, not people.
- Make room for different experience levels, languages, identities, and accessibility needs.
- Disclose uncertainty and provide reproducible evidence when making technical or security claims.
- Protect private data. Redact account details, local paths, prompts, credentials, and diagnostics before sharing.

## Unacceptable behavior

- Harassment, discrimination, threats, sexualized conduct, or targeted insults.
- Publishing another person's private information without explicit permission.
- Deliberately misleading security claims, fabricated test evidence, or attempts to obtain credentials.
- Repeatedly disrupting discussions after a maintainer has asked for a change in behavior.

## Enforcement

Maintainers may edit or remove content, close discussions, reject contributions, or temporarily or permanently restrict participation when necessary to protect the community. Reports should be made privately through the repository owner's contact channel. If the report concerns that owner, use the hosting platform's abuse-reporting process.

Enforcement decisions should be proportionate, documented privately, and avoid unnecessary disclosure of the reporter's identity.
