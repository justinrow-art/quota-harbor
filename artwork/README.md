# Artwork provenance

The six theme backgrounds in `source-masters/` are AI-generated outputs made
for this project on 2026-07-17. They were generated without named-artist,
studio, franchise, character, logo or trademark references. They must not be
described as human-made artwork, and no claim of uniqueness, copyrightability
or guaranteed non-infringement is made.

The machine-readable source record, dimensions, prompt summaries and SHA-256 hashes are in `provenance/theme-assets.json`. The generator returned native 1254×1254 PNG images; they were not upscaled or represented as native 2048px output. Source masters retain available generation provenance metadata. Runtime copies are re-encoded as single-frame sRGB PNG without copied source metadata and bundled with the app only after mechanical and visual review. Wider runtime surfaces repeat and mirror tiles sized from the raster's actual pixel dimensions and the current display scale, so the image is never enlarged beyond its native pixels.

The app icon is project-native vector artwork rendered by `scripts/generate_app_icon.swift`; it is not one of the six generated theme illustrations.
