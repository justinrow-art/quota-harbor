# QuotaHarbor 主題素材規格

## 交付項目

- App 圖示：一張 2048 × 2048 px source master，構圖需能安全裁切為 macOS 圓角圖示。
- 六張卡片背景 source master：各為原生正方形且至少 1200 × 1200 px，對應莫蘭迪、賽博龐克、溫暖手繪動畫、玻璃感、素描、卡通插畫；不得上採樣冒充較高原生解析度。
- 設定頁縮圖重用相同 runtime 圖，不另存重複檔案；SwiftUI 於顯示時向下縮小。
- Runtime 輸出：每款一張原生 sRGB PNG，由 source master 等尺寸重新編碼；顯示時依實際像素尺寸與螢幕倍率切成不超過原生解析度的鏡像 tile，只能向下取樣，不得向上取樣。

## 共通視覺限制

- 不含文字、商標、人物肖像、受保護角色、創作者或工作室名稱。
- 中央與左上保留低細節區，避免與額度數字、標題和操作按鈕衝突。
- 視覺僅作裝飾；所有狀態仍由文字、SF Symbol、外框或圖樣共同表達，不以顏色作唯一提示。
- 明暗模式都須維持可讀性；素材會覆蓋語意色表面，不承擔文字對比責任。
- 不含透明追蹤資訊、EXIF、GPS、外部 URL、字型或可執行內容。

## 六個方向

1. **莫蘭迪**：低飽和灰粉、鼠尾草綠與霧藍，柔和幾何層次、安靜且專業。
2. **賽博龐克**：深靛背景、青紫光帶與細緻網格，控制亮度以免壓過數據。
3. **溫暖手繪動畫**：原創、溫暖、手繪質感的自然場景語彙；不得模仿或提及特定創作者、工作室或角色。
4. **玻璃感**：霧面玻璃、柔和折射、淺景深光斑；降低透明度時由程式改用不透明表面。
5. **素描**：米白紙張、石墨線條與細微交叉排線，避免高頻紋理干擾文字。
6. **卡通插畫**：原創圓潤幾何、明快但受控的配色、友善且不幼稚。

## 驗收

- source master 必須在所有支援的實際顯示倍率上不需放大。目前 1254 px source 在 Retina 2x 下讓每個 tile 最多覆蓋 627 × 627 pt；較寬或較高的 surface 會自動增加 tile，而非放大單張圖。若未來任一 tile 的實際像素需求超過原圖、或改成禁止重複的單幅構圖，必須先重生更大的原生 master，不得插值補足。
- 每個 runtime 檔都有 SHA-256、尺寸、建立工具／作者、日期、權利與授權紀錄。
- 經 ImageIO 單幀解碼、sRGB 轉換、移除 metadata 並決定性重新編碼後才可進 App bundle。
- 素材缺少來源或授權紀錄時，不得宣稱可公開發布。

## 2026-07-17 實作決策

- 生成服務實際回傳六張原生 1254 × 1254 PNG；prompt 中的 2048 意圖不等於實際像素，provenance 必須如實標為 1254。
- 六張圖通過 ImageIO 單幀 sRGB 決定性重編碼後，以 raw Copy Bundle Resources 交付，因現有 runtime 使用 `Data?`；AppIcon 才使用 asset catalog。
- 卡片在 raster 上方加入 palette-background 可讀性層，背景插畫不負責文字對比；若移除或降低該層，必須重跑明暗模式的逐像素對比驗證。

## 2026-07-23 多欄面板決策

- 一至四個來源的 surface 可達 272 × 340、520 × 340、768 × 340、1016 × 340 pt，窄螢幕四來源為 520 × 620 pt。
- Runtime 以 PNG IHDR 的實際像素尺寸除以 SwiftUI `displayScale` 計算每個 tile 的最大 point 尺寸；超出時按列／欄重複同一 cached image，奇數列與欄鏡像以降低接縫感。
- 1254 × 1254 px 素材在 2x 下，768 與 1016 pt 寬面板分成兩欄；每格分別為 384 與 508 pt 寬。520 × 620 pt 維持單格，以上皆不需向上取樣。
